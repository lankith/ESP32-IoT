
# Experiment 01: Temperature and Humidity Monitoring Using ESP32

## Objective
To measure temperature and humidity using a DHT22 sensor connected to an ESP32 and upload the readings to ThingSpeak using Wi-Fi.

## Components Used
- ESP32
- DHT22 Temperature and Humidity Sensor
- Resistor
- Wokwi Simulator
- ThingSpeak IoT Cloud

## Software and Platforms
- Wokwi
- Arduino IDE / Arduino framework
- ThingSpeak

## Output
Temperature and humidity readings are successfully uploaded to ThingSpeak and displayed as graphs.
